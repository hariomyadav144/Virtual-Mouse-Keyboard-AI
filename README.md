# Virtual Mouse & Keyboard AI

Yeh ek AI-based project hai jo aapke haath ke gestures (index aur middle finger) ka use karke mouse aur keyboard ko control karne ki suvidha deta hai.

## Features
- Fingers ke movement se mouse pointer control karna.
- Fingers ke beech ki doori measure karke keyboard typing karna.

## Requirements
- Python 3.x
- OpenCV
- MediaPipe
- PyAutoGUI

## Kaise Run Karein
1. Repository clone karein.
2. Run karein: python virtual_keyboard.py
